# Frontend notes

I want the application to look like a simple, well-made product, not a generic admin template.

- Use clear typography, consistent spacing and a restrained blue/teal accent.
- Build readable forms, product lists, details, receipt upload/review and the service history timeline.
- Make it usable on mobile as well as desktop.
- Show loading, empty, error and success states when they matter.
- Connect buttons to real functionality. If something isn't available yet, disable it clearly rather than pretending it works.
- Keep the dashboard tied to real API data. Do not use fake stats as the final implementation.
- Add accessible labels and keyboard focus. Don't rely only on colored badges to explain status.
- Prioritize useful layouts over decorative animations and giant hero sections.
